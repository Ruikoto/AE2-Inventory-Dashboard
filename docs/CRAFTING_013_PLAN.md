# 0.1.3-dev 实施约定

用户于 2026-10-22 确认：新增默认网格、保留列表、下单预览/确认/进度/取消、同网络共享订单与30天历史。仅管理 Dashboard 提交的订单，不新增个人账号、自动补货或其他终端订单采集。public 模式也允许下单及取消；craftingEnabled 默认 true，关闭后保留既有订单管理。

网格与列表共用 Worker、选择、收藏、筛选和区间统计。可合成零库存进入目录；网格按行虚拟化，最多120个挂载条目。排除无限项默认关闭，位于仅收藏右侧。沿用深浅主题与 MVVM，订单请求由独立 viewmodel 管理，隐藏/切网/退出时停止读取及拒绝过期响应。

无限标记仅用于目录显示和筛选，来自当前网络驱动器/ME箱子内 ExtendedAE InfinityCellInventory；不按数量阈值推断，不涵盖经存储总线接入的独立子网。合并标记取或，原始数量、身份、统计和历史公式保持不变。

游戏线程拥有原生计划和 CPU；HTTP 只使用不可变数据和有界命令。先持久化幂等提交意图再调用 AE。通过最小 CraftingCpuLogic Mixin 捕获本项目提交和结束事件，不依赖独立任务的空返回 link 或不可靠 isDone。原生 UUID 恢复失败时显示未知，不自动重下、不取消 CPU 上的其他任务。

SQLite 从 schema1 事务迁移到 schema2，新增能力标记与订单表；所有写入沿用唯一写线程，读取沿用两个连接及3秒取消。历史清理保护活动订单及所引用网络。完整接口和边界见 [协议](PROTOCOL.md)。

按模型/存储、原生适配、HTTP、网页、完整构建顺序集成；验收包括迁移回滚、重复提交、持久化失败、共享权限、关开关、重启/卸载/取消竞争、无限与有限大数、1440/1024/390px、10k/100k目录及真实隔离 Forge 合成。所有游戏写入测试只在新建空白本地世界进行。

交付源码、验证记录和0.1.3-dev构建产物；本轮不提交、推送、上传或重启生产服务器。客户端功能不变，不要求重做资源包。
