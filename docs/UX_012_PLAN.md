# 0.1.2-dev 实施约定

执行用户确认的界面、统计和性能改进。时间范围共用现有控件，表格及详情使用区间指标；缺口时使用最近连续段，明确实际起止时间。速率曲线默认五分钟滚动平均，可选一分钟/十五分钟，不跨段。

实现深色、浅色、自定义基础配色，站点保存主题；恢复上次网络，默认隐藏已确认空网络，未知状态不隐藏。共享 SVG 品牌/favicon、居中搜索图标、整行点击及独立收藏/对比操作。数量与速率默认双轴，同单位对比，不同单位分图；波动范围使用真实极值区间带。

服务端增加有界批量区间统计及统计依据字段，保留 API v1 和 schema v1；区间统计独立于显示粒度。后台 Worker 承担库存读取、解析、过滤、排序；视图只接收窗口数据。合并刷新请求，保持滚动、选择、缩放及图例，避免深响应式和图表全量重建。

验证包含统计边界与断档、主题和本地偏好、交互、图表、10k/100k 库存、六项曲线及持续刷新。记录实测，不把目标视为已通过。服务端保持 SQLite 三秒读取取消、两个读连接及独立写线程。

检查构建、差异及敏感文件后提交推送。按既有授权备份并上传服务端安装包，不重启，不改资源包、历史或配置；实际生效由用户手动重启后核查。
