# 0.1.1-dev 修复验证

日期：2026-10-21。仍为开发构建，不建立正式发布标签。

## 修复

现场旧 SQLite Forge 驱动的 ProgressHandler 存在跨连接取消串扰，已在 Windows 与 Linux 的独立内存数据库复现。移除该回调，改用绑定具体原生连接的取消任务；保留读取三秒墙钟限制，并防止已结束任务误伤后续操作。此版本 setQueryTimeout 仅控制 busy timeout，不能替代执行时间限制。

写入故障后关闭异常连接，回滚未提交事务并清除内存差分基线，随后在原数据库重建连接。补充资源引用和覆盖查询索引。schema 仍为 v1，不删除数据库或重建历史；过去丢失的采样不能回补。

客户端导出器同时包含空名称降级：空白或缺失名称使用注册 ID，保留资源身份及图标，避免单个默认物品使整个资源包无效。
