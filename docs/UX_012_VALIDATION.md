日期：2026-10-21。基线提交：2546ba7。此次实现基于用户确认的界面与统计计划，随后覆盖相关采集、存储、HTTP、资源包和网页生命周期，修复查明的问题。仍为开发版本，不创建正式发行标签。

## 最终行为

- 右上角深色、浅色、自定义主题，配色校验和本地保存；favicon 使用现有品牌图形。
- 现有时间范围同时控制表格及详情的净变化、平均净速率；不会使用最后一次采样的瞬时涨跌替代区间变化。缺数据时只使用最新连续段，显示真实起止时刻；单样本仍不制造速率。
- 数量与速率默认双轴，同单位叠加、不同单位分图；速率默认五分钟滚动平均，可选一分钟、十五分钟。波动范围绘制真实 min/max 区间；无额外极值时禁用并说明。
- 记住最近网络，默认隐藏已确认空网络，未知状态保留；设置可显示空网络。整行可点，收藏和对比按钮独立。
- Worker 完成分页读取、解析、精确数量索引、筛选排序；主线程仅持有可见窗口及最多六条曲线。刷新保留数值、滚动、缩放和图例；网络切换/隐藏/取消时丢弃过期请求，单次请求十五秒截止。
- mB/B 同时应用于库存、区间净变化和速率；统计响应缺省 null 时清除旧指标。浏览器拒绝存储时，设置在本次会话及网络切换中仍保留。

## 性能测量

Windows 11、AMD Ryzen 7 9800X3D、约 31.38 GiB 内存，Node 24.14.0、Chromium 156.0.8078.4（8 个逻辑处理器对测试可见）。本机存在其他开发进程，结果是观测值，不是 SLA。

| 场景 | 实测 |
|---|---|
| 10 网络 × 10000 精确资源，每项有独立分组，全部不变采样 | 十网络写入合计 144.29 ms |
| 同场景全部改变 | 十网络写入合计 13.21 s；高变化量仍可能导致队列丢样，不宣称达到采样周期内完成 |
| 批量统计 10000 精确资源、五页 | 53.28 ms；逐项验证 delta=79、rate=237，版本一致 |
| 20 个并发存储历史查询 | 20/20 成功，合计 21.90 ms |
| 100000 网页条目、6×1200 点、真实时间连续刷新十分钟 | 56 轮完整库存/统计扫描，57 次历史请求；帧间隔 P95 16.7 ms、P99 16.8 ms；主线程 >50 ms 长任务为 0，页面错误为 0，滚动位置保持 |
| 最终源码 10000 条目交互（20 次搜索） | 首次就绪 292 ms；输入到结果更新 P95 56.8 ms |
| 最终源码 100000 条目交互（20 次搜索） | 首次就绪 914 ms；输入到结果更新 P95 72.8 ms；帧间隔 P95 约 16.7 ms，无长任务 |
| 同上十分钟测试内存/DOM | 主线程采样堆 20.6–50.5 MiB、预热后 DOM 1174–1180；不包括 Worker 堆，也不等于服务器内存 |

十分钟测试使用本轮中途构建的独立生产快照以避免热更新扰动；最终源码另做短时交互测量。浏览器使用合成的本地 API，它验证前端调度和渲染，不测公网带宽、真实服务器吞吐或 AE 主线程成本。服务端性能数据来自实际 SQLite；两个测试边界分开报告。

短时交互结果达到本轮目标（10k 搜索 P95 ≤100 ms、100k ≤200 ms；帧间隔 P95 ≤20 ms）。不把本机结果当作低端设备、所有浏览器或公网部署保证。

复现浏览器性能：先运行 npm --prefix web run build，将 web/dist 复制到独立 .local/perf-dist，然后在 web 目录使用 node tools/browser.mjs test --config tests/performance/playwright.config.ts。默认 100k 场景运行十分钟；PERF_SECONDS 可缩短观测，PERF_OUTPUT 指定隔离输出目录。合成数据在 tests/browser/fixture.ts，所有运行测量文件保持 Git 忽略。
